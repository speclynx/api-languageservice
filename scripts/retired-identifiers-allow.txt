# Places where a name containing "apidom" is still correct, checked by
# scripts/check-retired-identifiers.sh. One rule per line: an extended regular
# expression matched against the whole `path:line:content` finding, a tab, and
# the reason it is not a finding. A rule that matches nothing fails the check,
# so this table cannot outlive what it excuses.
#
# ApiDOM is the upstream project this language service is built on
# (https://github.com/speclynx/apidom): a family of npm packages and the
# document model they parse into. It is not this project's name, and the rules
# below are the places where that distinction runs the right way.
#
# The rules are applied in order and each consumes the lines it matches, so the
# narrow ones come first: a rule broad enough to swallow `apidom-ls` would
# excuse the retired package name wherever it appeared.

^packages/apidom-ls-compat/	The compatibility package, which exists to carry the retired package name and reproduce what it advertised.
^(CHANGELOG|packages/api-languageservice/CHANGELOG)\.md:	Released history. The entries say what the commits said, and the note at the top of each file records that the identifiers in them refer to the predecessor private repository.
@speclynx/apidom-ls	The retired package name, named as retired in the rename notices, the end-of-life policy, the unlink script and the wrapper's build.
packages/apidom-ls-compat	The directory of the compatibility package, referenced from the documentation.
speclynx/apidom-internal	The predecessor private repository, named as the predecessor.
apidom-ls package of the ApiDOM project	NOTICE recording which upstream package this distribution was seeded from.
@speclynx/apidom-(core|datamodel|error|json-path|json-pointer|ns-|parser|reference|traverse)	The published names of the upstream ApiDOM packages this project depends on.
apidom-language-(service|types)	Module filenames of the language service itself, unchanged by the rename.
"apidom",	An npm keyword: people looking for a language service for ApiDOM should find this package.
speclynx/apidom\)	Links to the upstream ApiDOM repository.
SpecLynx ApiDOM	The upstream project, named in full.
ApiDOM (tree|ecosystem|element|elem)	The upstream document model, as a domain term.
apidom only	A parenthetical about upstream ApiDOM behaviour in the rules documentation.
^NOTICE:(55|57):	The NOTICE attribution for the upstream ApiDOM project.
latest-apidom-ls|APPROVED_LATEST_apidom_ls	The release workflow carries the compatibility package's registry state under a name derived from its own, which is the retired one.
